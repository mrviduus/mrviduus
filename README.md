## TextStack: finish the tech books you keep quitting

<p align="center">
  <a href="https://github.com/mrviduus/textstack"><img src="https://raw.githubusercontent.com/mrviduus/textstack/main/docs/demo.gif" alt="TextStack demo" width="640"></a>

Select any term, get an LLM explanation in your language that knows the book's domain, plus an MCP server for Claude Desktop and Cursor. Capped weekly spaced repetition, offline reading, EPUB / PDF / FB2.
ASP.NET Core · React · Expo · [Web](https://textstack.app/) · [Google Play](https://play.google.com/store/apps/details?id=app.textstack.mobile) · [Source](https://github.com/mrviduus/textstack) · [Why I built it](https://dev.to/mrviduus/i-quit-designing-data-intensive-applications-ddia-three-times-heres-what-i-build-on-the-fourth-5bom)
